# poison

- [`index.html`](index.html): Poison Browser.
- [`launcher/`](launcher/): **POISON Client**, a Windows launcher with Microsoft sign-in, automatic game and Java downloads, a 3D preview, music, cosmetics and 184 features. See [launcher/README.md](launcher/README.md).
- [`mod/`](mod/): the **POISON in-game client for 1.21.4** (Fabric).
- [`mod-1.8.9/`](mod-1.8.9/): the **POISON in-game client for 1.8.9** (Legacy Fabric), with 1.7 animations.

Both clients have the glow HUD, effects (jump circles, China hat, trails, hit and kill effects), motion blur, butterfly knife, self chams and music player. The launcher installs the right one automatically.
