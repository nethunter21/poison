# poison

- [`index.html`](index.html): Poison Browser.
- [`launcher/`](launcher/): **POISON Client**, a Windows launcher with Microsoft sign-in, automatic game and Java downloads, a 3D preview, music, cosmetics and 184 features. See [launcher/README.md](launcher/README.md).
- [`mod/`](mod/): the **POISON in-game client** (Fabric 1.21.4): client menu, HUD, motion blur, butterfly knife, self chams, music player. The launcher installs it automatically.
