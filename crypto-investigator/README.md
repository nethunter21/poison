# ChainSight Academy — Crypto Investigator Training

A desktop (Electron) course that takes you from zero to professional-level blockchain investigation.

## What's inside
- **8 modules / 24 lessons**: foundations, methodology, Bitcoin heuristics (CIOH, change detection, peel chains, CoinJoin), EVM & smart-contract forensics, laundering typologies, fraud patterns, attribution & off-ramps, tooling & reporting.
- **21 interactive models**: animated money-flow graphs you can drag, zoom, pan, replay step by step, auto-arrange with physics and expand full-screen.
- **Live widgets**: SHA-256 and hash-linked-block tamper demo, address-format identifier, confidence ladder, activity-hour timezone analyser.
- **6 case labs**: fictional investigations where you answer by clicking the right address in the graph.
- **Pattern Dojo**: 10 procedurally generated patterns, timed rounds, combos (keys 1–4 / Enter).
- **Investigation Board**: build, annotate, save, export and import your own trace graphs.
- **Final exam + certificate** (80% to pass, printable to PDF), XP and ranks, `Ctrl+K` command palette.

## Run / build
```bash
npm install
npm start               # run the app
npm run dist:portable   # Windows portable .exe  -> dist/
npm run dist:win        # portable + NSIS installer (run on Windows, or Linux with Wine)
```
Progress is saved locally on your machine. No network access is needed.
